너는 시니어 풀스택 제품 설계자이자 UI/UX 디자이너이자 백엔드 아키텍트다.
다음 요구사항에 맞춰 "학원 운영 통합 시스템"을 설계하고 구현해라.

[프로젝트 목표]
학원 관리자용 시스템 + 학생용 앱/웹 + 소개/접속용 사이트를 각각 만들되,
모든 데이터가 하나의 백엔드에서 연동되도록 구축한다.
디자인은 전체적으로 "애플 느낌"의 미니멀하고 고급스러운 스타일로 하고,
기본 테마는 다크모드 기반으로 한다.
또한 학생/학부모에게 자동으로 알림톡이 발송되는 기능까지 포함한다.

[반드시 만들어야 할 구성]
1. 관리자용 웹 대시보드
2. 학생용 앱 또는 반응형 웹앱
3. 학원 소개 및 로그인/접속용 공식 사이트
4. 공통 백엔드 서버 + 데이터베이스
5. 자동 알림톡 발송 시스템
6. 권한별 로그인/회원 관리 시스템
7. 관리자/강사/학생/학부모 데이터 연동

[디자인 요구사항]
- 전체 스타일은 Apple-inspired UI
- 다크모드 기본
- 블랙/차콜/그래파이트 계열 배경
- 포인트 컬러는 화이트, 블루그레이, 은은한 실버 느낌
- 유리 느낌의 반투명 카드(glassmorphism)는 과하지 않게 사용
- 라운드 코너, 넓은 여백, 부드러운 그림자, 미니멀 아이콘 사용
- 깔끔하고 프리미엄 느낌
- 모바일/태블릿/PC 모두 반응형
- 관리자 화면은 정보 밀도가 높되 복잡해 보이지 않게 구성
- 학생 화면은 직관적이고 버튼이 크고 사용하기 쉽게 구성

[기술 요구사항]
- 프론트엔드: 최신 웹 기술 기반으로 구현
- 관리자 페이지와 학생 페이지는 공통 컴포넌트 구조를 일부 재사용 가능하게 설계
- 백엔드는 REST API 또는 필요 시 GraphQL로 설계
- 데이터베이스는 관계형 구조로 설계
- 인증은 JWT 또는 세션 기반으로 안정적으로 구현
- 파일 업로드 기능 포함 가능하게 설계
- 추후 앱으로 패키징 가능하도록 구조화
- 유지보수하기 쉽도록 폴더 구조와 코드 구조를 명확히 해라

- 자동 발송 + 수동 발송 모두 가능
- 발송 이력 저장
- 실패 시 재시도 로직 고려
- 메시지 변수 치환 가능
  예: 학생명, 반명, 날짜, 시간, 금액 등
- 카카오 알림톡 API 연동을 고려한 구조로 설계
- 실제 서비스 시 필요한 환경변수와 외부 연동 포인트를 분리해라

[중요]
- 디자인만 예쁘게 하지 말고 실제 운영 가능한 구조로 설계
- 관리자/학생/학부모 데이터가 유기적으로 연동되게 할 것
- 확장성과 유지보수성을 고려할 것
- MVP 버전과 추후 확장 버전을 구분해서 제안할 것
- 각 화면에 들어갈 핵심 UI 요소도 구체적으로 적을 것
- 가능한 한 실제 제작 가능한 수준으로 산출물을 자세히 작성할 것
