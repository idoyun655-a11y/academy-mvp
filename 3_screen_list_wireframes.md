# 학원 운영 통합 시스템: 화면 목록 및 와이어프레임 설명

본 문서는 학원 운영 통합 시스템의 주요 화면 목록과 각 화면에 대한 와이어프레임 수준의 설명을 제공합니다. 관리자 웹, 학생/학부모용 반응형 웹앱, 학원 소개 및 접속용 공식 사이트의 MVP 기능을 중심으로 설명하며, 이전에 정의된 UI/UX 디자인 가이드라인을 준수합니다.

## 1. 공통 UI 요소 및 디자인 원칙

모든 화면은 Apple-inspired 다크모드 디자인 원칙을 따릅니다. 주요 공통 UI 요소는 다음과 같습니다.

*   **레이아웃**: 좌측 사이드바 (메뉴), 상단 헤더 (로고, 사용자 정보, 알림), 메인 콘텐츠 영역으로 구성됩니다. 모바일에서는 사이드바가 햄버거 메뉴로 전환됩니다.
*   **색상**: 블랙/차콜/그래파이트 계열 배경, 화이트/블루그레이/실버 포인트 컬러.
*   **컴포넌트**: 라운드 코너, 넓은 여백, 부드러운 그림자, 미니멀 아이콘이 적용된 카드형 UI를 기본으로 합니다. 입력 필드, 버튼, 배지 등은 통일된 스타일을 가집니다.
*   **반응형**: 모든 화면은 모바일, 태블릿, PC 환경에 최적화된 반응형 디자인을 제공합니다.

## 2. 관리자 웹 화면 목록 및 와이어프레임 설명 (MVP)

관리자 웹은 학원 운영의 핵심 기능을 제공하며, 정보 밀도가 높지만 복잡해 보이지 않도록 구성합니다.

### 2.1. 로그인 페이지

*   **목표**: 관리자 계정으로 시스템에 안전하게 로그인.
*   **레이아웃**: 중앙 정렬된 로그인 폼. 좌측 또는 상단에 학원 로고 및 시스템명.
*   **주요 UI 요소**: 
    *   **학원 로고/시스템명**: 상단 중앙 또는 좌측 상단.
    *   **제목**: 
`로그인`.
    *   **입력 필드**: 아이디 (이메일), 비밀번호. (라운드 코너, 다크모드 스타일).
    *   **버튼**: `로그인` (블루그레이 Primary 버튼).
    *   **링크**: `비밀번호 찾기`.
*   **와이어프레임 스케치**: 
    ```text
    +-----------------------------------+
    |          [학원 로고]              |
    |        학원 통합 시스템         |
    |                                   |
    |             로그인                |
    |                                   |
    |     +-----------------------+     |
    |     |   아이디 (이메일)     |     |
    |     +-----------------------+     |
    |                                   |
    |     +-----------------------+     |
    |     |   비밀번호            |     |
    |     +-----------------------+     |
    |                                   |
    |     [ ] 로그인 유지               |
    |                                   |
    |     +-----------------------+     |
    |     |        로그인         |     |
    |     +-----------------------+     |
    |                                   |
    |          비밀번호 찾기            |
    +-----------------------------------+
    ```

### 2.2. 관리자 대시보드

*   **목표**: 학원 운영의 핵심 지표 및 현황을 한눈에 파악.
*   **레이아웃**: 좌측 사이드바, 상단 헤더, 메인 콘텐츠 영역. 메인 콘텐츠는 통계 카드, 오늘 수업 리스트, 최근 공지 등으로 구성.
*   **주요 UI 요소**: 
    *   **상단 헤더**: 학원명, 사용자 프로필, 알림 아이콘.
    *   **좌측 사이드바**: 대시보드, 학생 관리, 강사 관리 등 메뉴 목록 (아이콘 포함).
    *   **통계 카드 (4개)**: `오늘 수업 수`, `출석 현황`, `미납 현황`, `최근 상담 일정`. 각 카드에는 큰 숫자와 간략한 설명, 상태에 따른 색상 배지 (예: 미납 현황은 주황색).
    *   **오늘 수업 리스트**: 카드형 리스트로 표시. 각 카드에는 `반 이름`, `시간`, `강사`, `인원` 정보.
    *   **최근 공지**: 카드 형태로 분리된 최신 공지 목록. `제목`, `작성일`.
*   **와이어프레임 스케치**: 
    ```text
    +-------------------------------------------------------------------+
    | [로고] 학원명                 [알림] [사용자 프로필]             |
    +-------------------------------------------------------------------+
    |             |                                                   |
    | 대시보드    |  +------------------+ +------------------+       |
    | 학생 관리   |  | 오늘 수업 수     | | 출석 현황        |       |
    | 강사 관리   |  | [숫자]           | | [숫자]           |       |
    | ...         |  +------------------+ +------------------+       |
    |             |                                                   |
    |             |  +------------------+ +------------------+       |
    |             |  | 미납 현황        | | 최근 상담 일정   |       |
    |             |  | [숫자]           | | [숫자]           |       |
    |             |  +------------------+ +------------------+       |
    |             |                                                   |
    |             |  오늘 수업                                        |
    |             |  +--------------------------------------------+   |
    |             |  | [반이름] 시간 강사 인원                    |   |
    |             |  +--------------------------------------------+   |
    |             |  | [반이름] 시간 강사 인원                    |   |
    |             |  +--------------------------------------------+   |
    |             |                                                   |
    |             |  최근 공지                                        |
    |             |  +--------------------------------------------+   |
    |             |  | [제목] 작성일                              |   |
    |             |  +--------------------------------------------+   |
    |             |  | [제목] 작성일                              |   |
    |             |  +--------------------------------------------+   |
    +-------------------------------------------------------------------+
    ```

### 2.3. 학생 관리 페이지

*   **목표**: 학생 정보 등록, 조회, 수정, 삭제 및 반 배정, 수강 과목 관리.
*   **레이아웃**: 좌측 사이드바, 상단 헤더, 메인 콘텐츠 영역. 메인 콘텐츠는 검색/필터 영역, 학생 목록 (카드형), 학생 상세 정보/등록 폼으로 구성.
*   **주요 UI 요소**: 
    *   **검색/필터 영역**: 상단 고정. `검색창` (학생 이름, 학번), `필터 드롭다운` (반, 수강 상태).
    *   **학생 목록**: 카드형 리스트. 각 카드에는 `학생 이름`, `아바타 (이니셜 원형)`, `출결 상태 컬러 배지`, `수강 과목 수`, `학부모 연락처`. 우측에 `상태 배지` (예: 재원, 휴원).
    *   **액션 버튼**: `학생 등록` (Primary 버튼).
    *   **학생 상세/등록 폼**: 모달 또는 별도 페이지. `이름`, `생년월일`, `연락처`, `학부모 정보`, `반 배정`, `수강 과목 선택` 등 입력 필드.
*   **와이어프레임 스케치**: 
    ```text
    +-------------------------------------------------------------------+
    | [로고] 학원명                 [알림] [사용자 프로필]             |
    +-------------------------------------------------------------------+
    |             |                                                   |
    | 대시보드    |  학생 관리                                        |
    | 학생 관리   |  +--------------------------------------------+   |
    | 강사 관리   |  | [검색창]                               [필터] |   |
    | ...         |  +--------------------------------------------+   |
    |             |                                                   |
    |             |  +--------------------------------------------+   |
    |             |  | [아바타] 학생 이름 (재원)                  |   |
    |             |  | 수강 과목: 3개                             |   |
    |             |  | 학부모: 010-xxxx-xxxx                      |   |
    |             |  +--------------------------------------------+   |
    |             |  +--------------------------------------------+   |
    |             |  | [아바타] 학생 이름 (휴원)                  |   |
    |             |  | 수강 과목: 0개                             |   |
    |             |  | 학부모: 010-yyyy-yyyy                      |   |
    |             |  +--------------------------------------------+   |
    |             |                                                   |
    |             |  +--------------------------------------------+   |
    |             |  |             + 학생 등록 +                |   |
    |             |  +--------------------------------------------+   |
    +-------------------------------------------------------------------+
    ```

### 2.4. 반/수업 관리 페이지

*   **목표**: 반 생성, 시간표 관리, 수업별 출결 체크.
*   **레이아웃**: 좌측 사이드바, 상단 헤더, 메인 콘텐츠 영역. 메인 콘텐츠는 반 목록, 반 상세 정보/등록 폼, 시간표 뷰로 구성.
*   **주요 UI 요소**: 
    *   **반 목록**: 카드형 리스트. 각 카드에는 `반 이름`, `담당 강사`, `수강 인원`, `수업 요일/시간`.
    *   **액션 버튼**: `반 생성` (Primary 버튼).
    *   **반 상세/등록 폼**: 모달 또는 별도 페이지. `반 이름`, `담당 강사`, `수강 정원`, `수업 요일`, `수업 시간` 등 입력 필드.
    *   **시간표 뷰**: 주간 또는 월간 캘린더 형태로 수업 스케줄 표시. 각 수업 블록 클릭 시 상세 정보 (출결 체크) 모달.
*   **와이어프레임 스케치**: 
    ```text

    | [로고] 학원명                 [알림] [사용자 프로필]             |

    | ...         |                                                   |
    |             |  +--------------------------------------------+   |
    |             |  | [반 이름]                                  |   |

    |             |  | 수강 인원: 15명                            |   |
    |             |  | 수업: 월,수,금 19:00-21:00                 |   |
    |             |  +--------------------------------------------+   |
    |             |  +--------------------------------------------+   |
    |             |  | [반 이름]                                  |   |
    |             |  | 담당 강사: [강사명]                        |   |
    |             |  | 수강 인원: 10명                            |   |

    |             |  +--------------------------------------------+   |
    |             |                                                   |
    |             |  +--------------------------------------------+   |
    |             |  |             + 반 생성 +                  |   |
    |             |  +--------------------------------------------+   |
    +-------------------------------------------------------------------+
    ```

### 2.5. 출결 관리 페이지

*   **목표**: 수업별 출결 현황 조회 및 수정.
*   **레이아웃**: 좌측 사이드바, 상단 헤더, 메인 콘텐츠 영역. 메인 콘텐츠는 날짜/반 선택 영역, 출결 현황 테이블/리스트로 구성.
*   **주요 UI 요소**: 
    *   **날짜/반 선택**: `날짜 선택기`, `반 선택 드롭다운`.
    *   **출결 현황**: 테이블 또는 카드형 리스트. `학생 이름`, `출결 상태` (출석, 지각, 결석, 조퇴), `비고` (수정 가능). 출결 상태는 색상 배지로 표시.
    *   **액션 버튼**: `저장`, `출결 내역 다운로드`.
*   **와이어프레임 스케치**: 
    ```text
    +-------------------------------------------------------------------+
    | [로고] 학원명                 [알림] [사용자 프로필]             |
    +-------------------------------------------------------------------+
    |             |                                                   |
    | 대시보드    |  출결 관리                                        |
    | 학생 관리   |  +--------------------------------------------+   |
    | ...         |  | [날짜 선택]                      [반 선택] |   |
    | 출결 관리   |  +--------------------------------------------+   |
    |             |                                                   |
    |             |  +--------------------------------------------+   |
    |             |  | 학생 이름     | 출결 상태 | 비고           |   |
    |             |  |--------------------------------------------|   |
    |             |  | 김철수        | 출석      |                |   |
    |             |  | 이영희        | 지각      | (10분 늦음)    |   |
    |             |  | 박민수        | 결석      | (병결)         |   |
    |             |  +--------------------------------------------+   |
    |             |                                                   |
    |             |  +--------------------------------------------+   |
    |             |  |          + 저장 +  + 다운로드 +          |   |
    |             |  +--------------------------------------------+   |
    +-------------------------------------------------------------------+
    ```

*   **주요 UI 요소**:

## 3. 학생/학부모용 반응형 웹앱 화면 목록 및 와이어프레임 설명 (MVP)

학생/학부모용 웹앱은 직관적이고 사용하기 쉬운 인터페이스를 제공하며, 핵심 정보를 빠르게 확인할 수 있도록 구성합니다.

### 3.1. 로그인 페이지

*   **목표**: 학생/학부모 계정으로 시스템에 로그인.
*   **레이아웃**: 관리자 로그인 페이지와 유사하나, 학생/학부모에 특화된 문구 및 디자인.
*   **주요 UI 요소**: 
    *   **학원 로고/시스템명**: 상단 중앙.
    *   **제목**: `학생/학부모 로그인`.
    *   **입력 필드**: 아이디 (이메일/학생 코드), 비밀번호.
    *   **버튼**: `로그인` (Primary 버튼).
    *   **링크**: `회원가입`, `비밀번호 찾기`.
*   **와이어프레임 스케치**: 
    ```text
    +-----------------------------------+
    |          [학원 로고]              |
    |        학원 통합 시스템         |
    |                                   |
    |      학생/학부모 로그인           |
    |                                   |
    |     +-----------------------+     |
    |     |   아이디 (이메일)     |     |
    |     +-----------------------+     |
    |                                   |
    |     +-----------------------+     |
    |     |   비밀번호            |     |
    |     +-----------------------+     |
    |                                   |
    |     +-----------------------+     |
    |     |        로그인         |     |
    |     +-----------------------+     |
    |                                   |
    |       회원가입 | 비밀번호 찾기    |
    +-----------------------------------+
    ```

### 3.2. 홈 화면

*   **목표**: 학생에게 가장 중요한 정보를 한눈에 제공.
*   **레이아웃**: 상단 헤더, 핵심 정보 카드 (다음 수업, 최근 공지, 과제, 출석, 성적 요약), 하단 내비게이션 바.
*   **주요 UI 요소**: 
    *   **상단 헤더**: 학원명, 사용자 이름, 알림 아이콘.
    *   **핵심 정보 카드**: 
        *   **다음 수업**: `반 이름`, `시간`, `강사`.

## 4. 학원 소개 및 로그인/접속용 공식 사이트 화면 목록 및 와이어프레임 설명 (MVP)

학원 소개 사이트는 학원의 얼굴 역할을 하며, 고급스럽고 신뢰감 있는 랜딩 페이지로 구성됩니다.

### 4.1. 메인 랜딩 페이지

*   **목표**: 학원 정보 제공 및 시스템 진입점 역할.
*   **레이아웃**: 풀스크린 히어로 섹션, 학원 소개, 강의 과정, 강사진, 문의/연락처 섹션, 푸터.
*   **주요 UI 요소**: 
    *   **네비게이션 바**: `학원 소개`, `강의 과정`, `강사진`, `수강 문의`, `로그인` 링크.
    *   **히어로 섹션**: 학원 슬로건, 배경 이미지/영상, `상담 신청` 버튼.
    *   **학원 소개 섹션**: 학원 개요, 교육 철학 등 텍스트 및 이미지.
    *   **강의 과정 섹션**: 주요 강의 과정 카드형 목록.
    *   **강사진 섹션**: 강사 프로필 카드형 목록.
    *   **수강 문의 섹션**: 연락처 정보, `상담 신청 폼` 링크/버튼.
    *   **푸터**: 저작권 정보, 소셜 미디어 링크.
*   **와이어프레임 스케치**: 
    ```text
    +-------------------------------------------------------------------+
    | [로고] 학원 소개 | 강의 과정 | 강사진 | 수강 문의 | [로그인] |
    +-------------------------------------------------------------------+
    |                                                                   |
    |               [학원 슬로건]                                       |
    |               [배경 이미지/영상]                                  |
    |               + 상담 신청 +                                       |
    |                                                                   |
    +-------------------------------------------------------------------+
    |                                                                   |
    |                   학원 소개                                       |
    |                   [텍스트 및 이미지]                              |
    |                                                                   |
    +-------------------------------------------------------------------+
    |                                                                   |
    |                   강의 과정                                       |
    |       [카드1]       [카드2]       [카드3]                           |
    |                                                                   |
    +-------------------------------------------------------------------+
    |                                                                   |
    |                   강사진                                          |
    |       [강사1]       [강사2]       [강사3]                           |
    |                                                                   |
    +-------------------------------------------------------------------+
    |                                                                   |
    |                   수강 문의                                       |
    |                   [연락처 정보]                                   |
    |                   + 상담 신청 폼 +                                |
    |                                                                   |
    +-------------------------------------------------------------------+
    |                                                                   |
    |                   푸터 (저작권, 소셜 미디어)                      |
    |                                                                   |
    +-------------------------------------------------------------------+
    ```

### 4.2. 상담 신청 폼 페이지

*   **목표**: 잠재 고객의 상담 신청 정보를 접수.

*   **주요 UI 요소**: 
    *   **입력 필드**: `신청자 이름`, `연락처`, `이메일`, `관심 강의 과정`, `문의 내용` (텍스트 에어리어).
    *   **개인정보 처리 동의**: 체크박스.
    *   **버튼**: `신청하기` (Primary 버튼).
